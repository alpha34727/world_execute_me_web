## 修改指令

### 01 prompt（構圖 3、絢麗 2）
1. **框太大，文字只佔一半**。目前框是 x 300–1620，全句打完後文字只到 x≈1030，右側 590 px 是空的灰框（f1272）。
   - 框改為 x 420–1500、y 470–610；
   - 文字字級從約 52 px 提到 60 px；
   - 讓 `world.execute(me);` 打完時，游標停在框寬的 75% 左右。
2. **me 被框蓋住**。spark 在 (905, 520)，正好躲在框後面，只透出一點暗淡的星形。這一鏡是「you 在對 me 說話」，me 應該看得見、而且在聽：
   - spark 移到框上方 (960, 330)，直徑約 110 px；
   - 每打出一個 token（beat 32／33／34），spark 就脈動一次（0.25 拍衰減）；
   - 同時從游標往 spark 射一束藍色粒子（you 的粒子，現在只在游標旁散開，往 (960, 330) 收束即可）。
3. **能量層**：bar 8 是合成器整層進場，畫面卻是全章最靜的一張。每個 token 打出的那一幀：
   - 對應的 BPE 切塊從框內「掉」到切塊列，帶 200–400 顆橘／灰粒子濺開；
   - 背景的 intro 世界（環、方框、權重柱）隨 rms_other 微亮。
   目標：f1218 和 f1272 都要有明顯的動態焦點，而不是靜止的介面截圖。
4. **切塊列有缺口**。f1272 的 `e`（801）和 `me`（910）之間空約 70 px，因為 `(`、`)`、`;` 沒有切塊；但 `.` 有切塊。標示要誠實，二擇一：
   - (a) 詞彙表外的字元畫成灰色切塊，標 `?`、id 記 `—`；
   - (b) 切塊列只列出真的有 token 的部分，緊密排列，不要留洞。
5. **切塊壓到 3D 線條**。f1218 的切塊列（x 395–615, y 650–700）疊在 intro 方框的上緣邊上。切塊列後方 ±40 px 內的 3D 線條壓到 ≤20%，比照 hudGuard。
6. **地平線像 UI 分隔線**。f1218 在 y≈340、f1272 在 y≈228 有一條橫貫全寬的細亮線。兩端 300 px 以 smoothstep 淡出，亮度降到 faint 的 60%。

### 02 enter（可讀性 3；其餘 ≥4）

## 章節層級

1. **能量曲線和音樂相反**。inst1 是合成器整層進來的 8 小節，應該是「中高 → 推向 v1」。實際的視覺能量是：
   - prompt：低（靜態介面）
   - enter：**最高**（bar 9）
   - forward：驟降（bar 10–12）
   - galaxy：中低
   - plan：**最低**（bar 14–16）
   最後 4 小節是全章最空的畫面，對不上音樂，也接不上 v1。依「每個 3D 鏡頭都要有 GPU 粒子能量層」：
   - forward：≥5000 顆殘差流粒子；
   - galaxy：字詞星雲＋邊上的粒子流；
   - plan：spark 的粒子噴流，數量要逐拍累積。
   目標曲線：prompt 3 → enter 5 → forward 4 → galaxy 4 → plan 5（在 bar 16 前一拍到頂）。

2. **從 intro 的 SIMULATION 接進來是順的**。prompt 保留了 intro 世界的環、方框、殼和權重柱，機位往上搖、出現地平線，延續性很好。唯一的斷點是 spark：simulation 結束時 spark 是世界的中心，prompt 一開場就把它藏到框後面（見 prompt 第 2 點）。

3. **you 的藍色斷線了**。藍色只在 prompt（游標＋游標旁的藍粒子）出現，之後 4 個鏡頭、約 12.9 s 沒有任何藍色。而 v1.01 要求 you 是藍的，v1 的故事全是「give you my X」。必須保留一條細的藍線貫穿本章：
   - enter：使用者訊息的藍色豎線；
   - galaxy：`your` 的點和標籤；
   - plan：點雲外的藍游標。

4. **轉場品質**：
   - **forward → galaxy 的 whip 兩端是空白幀**（品質紅線）。forward 終點 f1642 只剩一片暗色和左側一點橘色模糊；galaxy 起點 f1643 只有右半邊的灰色橫紋。甩鏡兩端的影像都要認得出來：forward 的殘差流沿甩鏡方向拉長，galaxy 的點從另一側拉進來。模糊長度減半。
   - **galaxy → plan 的 xfade** 在兩張相同的圖之間做，等於沒有轉場（見 plan 第 2 點）。
   - **enter → forward 的 glide** 中段是暖色長方形碎片與速度線（f1420／f1421）。可以接受，但讓那些長方形在 forward 開頭就成為可辨認的層平面（偏軸機位，見 forward 第 1 點）。這樣 glide 才是「穿過 spinner 落進層疊」，而不是兩堆不相干的碎片。
