## 逐鏡頭

**ifican（f10064）**
- 與 c1.01 同構圖：滿屏放射狀紅橘光線、中央 spark、一圈橢圓光環，轉成紅橘後能量感很夠，whip 進場有速度。字幕 `> EXECUTION`（上一章尾）還在上一行，接得順。
- 背景的白色亮點太多太亮（約幾百個接近純白的小圓點，散在整個畫面，如 (30–260, 700–900) 一帶），與 spark 的白核心搶層次；規範「背景餘燼用中性灰／白」，但這裡亮度太高，圖面偏髒（建議 3）。

**givethem（f10190）**
- 4096 個星號格子是整章的視覺基底，與 chant 末尾連續；me 的 spark 在中央有柔邊暗圈，找得到。`them` 時由金轉紅橘、每字一脈衝，概念清楚。

- 密度過高：左右兩側的星號簇被透視拉成粗大的「箭頭」(960±40, 40–260)，看起來像是 bug 而非 3D；中景亂線很多。扣在構圖／風格 4。
